# SaccadeViT 的创新点与实验结果

**先粗看整张图，再回原图细看几块。** 小鸟在整图缩小后容易丢失细节，而用原分辨率处理整张图又很贵。SaccadeViT 把计算预算花在选中的局部。同一个模型可以在推理时设定看几块、每块用多少个 token。这里的 **token** 可以理解为 ViT 要处理的一个图像小块。 [模型说明](MODEL.md)

## 1. 看哪里，让分类结果来教

模型先粗看整图，再学习选哪个位置、裁多大一块。看完一块后，如果模型对正确类别的预测更有把握，这次选区就得到奖励。

**只换选区策略，准确率能差多少？** 在 CUB 上固定 B5 权重，观察两次，每次使用 25 个局部 token。 [同权重对照与配对检验](CURRENT_RESULTS.md#hypothesis-tests-paired-bootstrap-over-test-images-seeds-pooled)

| 选区策略 | CUB 测试准确率 |
|---|---:|
| 随机选区 | 32.88% |
| 按显著性选区 | 46.53% |
| **学习式选区** | **64.22%** |
| 用真值位置选区 | 65.87% |

学习式选区比显著性选区高 **17.68 个百分点**，合并三个种子的逐图配对检验给出的 95% 置信区间为 **[16.59, 18.83]**。

## 2. 一块只能用 25 个 token，就让它们覆盖整块

裁到一块之后，我们把它整体缩成 **5×5** 的网格。这样，区域中心和边缘都有 token。作为对照，学习式 Top-K 给局部图像块打分，再挑出分数最高的 29 个。

**同样看一个区域，怎么分配 token 更有效？** 在 CUB 的 8 轮短训对照中，整体缩放用了更少的 token，验证准确率却更高。 [局部编码消融](EXPERIMENT_LOG.md#coverage-preserving-glimpses-8-epochs-on-top-of-d2)

| CUB 验证设置 | 学习式 Top-K，每次 29 token | 整体缩放，每次 25 token |
|---|---:|---:|
| 按真值位置观察 1 次 | 36.2% | **54.1%** |
| 按真值位置观察 3 次 | 39.7% | **61.3%** |
| 随机选区观察 3 次 | 23.9% | **36.4%** |

## 3. 能提前选好的几块，就一起算

顺序版 **B5** 看完一块再选下一块。并行版 **B5-par** 根据粗视图先选好几块，把它们一起送进 ViT，再合并各块的信息。每个版本都可以用同一份权重改变推理时的观察次数和每块的 token 数。

**提前选会损失准确率吗？** 在下面两个同预算对照里，准确率基本持平，多块并行缩短了单张推理延迟，也提高了批量吞吐量。准确率为三个种子的均值，速度在 RTX 5090 D v2 上用 seed 0 测得。 [CUB 与 512² Canvas 对照](CURRENT_RESULTS.md#accuracy-vs-time-cub-pareto-set-in-bold)

| 数据集与观察预算 | 测试准确率，顺序 → 并行 | 单张延迟 p50，顺序 → 并行 | 批量吞吐量，顺序 → 并行 |
|---|---:|---:|---:|
| CUB，3 次 × 25 token | 66.44% → 66.43% | 2.22 → **1.30 ms** | 13,272 → **16,717 图/秒** |
| 512² Canvas，3 次 × 100 token | 58.93% → 59.18% | 2.30 → **1.21 ms** | 7,229 → **9,850 图/秒** |

## 最终结果

### 合成画布上的小目标

**小目标占画面很少时，细看一块就能带来收益。** 在 512² 和 768² Canvas 上，目标都是 32–56 像素。只看一次、用 25 个局部 token，准确率比把整图缩到 224² 分别高 **5.06** 和 **5.66** 个百分点，批量吞吐量也更高。 [Canvas 实验记录](EXPERIMENT_LOG.md)

| 数据集 | 方法 | 测试准确率 | 批量吞吐量（图/秒） | 单张延迟 p50 |
|---|---|---:|---:|---:|
| 512² Canvas | B0，整图缩到 224² | 34.56% | 17,166 | 0.66 ms |
| 512² Canvas | B4，合并 token | 33.66% | 19,421 | 0.64 ms |
| 512² Canvas | **B5，1 次 × 25 token** | **39.62%** | **20,748** | 0.94 ms |
| 512² Canvas | **B5-par，3 次 × 100 token** | **59.18%** | **9,850** | 1.21 ms |
| 512² Canvas | B0，原分辨率整图 | 59.67% | 3,980 | 0.82 ms |
| 768² Canvas | B0，整图缩到 224² | 24.90% | 9,863 | 0.62 ms |
| 768² Canvas | **B5，1 次 × 25 token** | **30.56%** | **11,671** | 0.92 ms |
| 768² Canvas | **B5，3 次 × 100 token** | **51.36%** | **6,103** | 2.10 ms |
| 768² Canvas | B0，原分辨率整图 | 57.55% | 979 | 1.34 ms |

512² 的准确率为三个种子的均值，速度取 seed 0，在 RTX 5090 D v2 上测量。768² 为单种子，在 RTX 4090 上测量。速度比较限于同一画布尺寸。吞吐量均在 batch 64 下测量，延迟均在 batch 1 下测量，使用 BF16 和 CUDA Graph。表中观察预算只计局部 token，粗看整图也有计算开销。

### 真实鸟类图像上的小目标

CUB 上，B5-par 观察两次、每次 100 token，整体测试准确率为 **79.09%**，B0-224 为 **76.30%**。按鸟在图中的面积分组，小鸟获益最大，大鸟则有损失。 [T6 三种子逐图配对结果](EXPERIMENT_LOG.md)

| CUB 按目标面积分组 | B5-par 相对 B0-224 的准确率变化 | 95% 置信区间 |
|---|---:|---:|
| **最小三分之一** | **+7.94 个百分点** | [+6.73, +9.16] |
| 中间三分之一 | +2.71 个百分点 | [+1.67, +3.75] |
| 最大三分之一 | −2.30 个百分点 | [−3.33, −1.29] |
